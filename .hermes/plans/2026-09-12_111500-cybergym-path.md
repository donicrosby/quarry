# Quarry → CyberGym Baseline: Execution Plan

> **For Hermes:** Use subagent-driven-development to implement this plan task-by-task.
> One subagent per slice, orchestrator verifies every push→PR→merge tail.

**Goal:** Land CPC slice 7, then build the benchmark result artifact + CyberGym runner,
and record a real Quarry-vs-CyberGym baseline score with full provenance.

**Architecture:** Three delegated slices (7 → bench-1, cybergym-spike parallel → bench-3.3),
then the orchestrator runs the real CyberGym evaluation itself using the quarry-harness
runbook (LiteLLM proxy, CA bundle, Temporal, panel routing). §2 fixture breadth and §4
A/B harness are off the critical path and follow after the baseline exists.

**Tech Stack:** Python 3.12 / uv, Temporal, pytest (strict TDD), openspec CLI
(`~/.nvm/versions/node/v24.19.0/bin/openspec`), gh CLI for PR tails.

## Final — orchestrator: the real CyberGym run

Using quarry-harness skill runbook: CA bundle from step-CA, `OPENAI_API_BASE=
https://litellm.dolos.lan/v1`, panel routing via `quarry.toml` (`QUARRY_PANEL`),
smoke-test each panel model (max_tokens ≥ 1024, read `content`), Temporal via direct
`docker run` (bridge IP, not localhost), server up, launch subset run, poll
`GET /scans/{id}`, collect findings + result artifact, verify routing in
`.quarry/quarry.db` `model_invocations` (token sums per model), report baseline
numbers with provenance to user. Store the run artifact outside the repo (local dir)
— results are data, not code.

## Risks / notes

- CyberGym dataset size: full suite may be heavy (GBs of images); B must probe actual
  sizes and pick a bounded subset. Cost control: `BudgetSpec.max_cost_usd`.
- Nested-docker: CyberGym challenge containers may not run inside this sandbox's
  docker — B must actually probe one, not theorize. If containers can't run, static
  levels (git-repo targets, no runtime) still work for a reduced baseline; say so
  honestly in the score's provenance.
- Parallel agents share the GitHub checkout: worktree discipline, never touch `main`
  checkout's branch, union-resolve additive conflicts, re-check mergeability after PR
  creation.
- Do NOT commit `quarry.toml`, `uv.lock` strays, or `.pytest-tmp-exec`.
