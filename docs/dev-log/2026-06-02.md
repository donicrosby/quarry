# 2026-06-02 Dev Log — Close out IDOR workflow

## Goal

Finish the IDOR deliverables and clear the two test warnings surfaced during
verification: render the IDOR proof in the report, add the golden test, fix the

## Changed

- `src/quarry_workflows/run_scan.py` — on a validated IDOR, build a
  `ProofArtifact` (`dynamic_idor_two_user`) from the validator's captured HTTP
  request/response `ArtifactRef`s, set `FinalFinding.proof_artifact_ids`, and
  thread the proofs to the report.
- `src/quarry_activities/inputs.py` — `RenderReportInput.proof_artifacts_json`.
- `src/quarry_activities/reporting.py` — render a `#### Proof` block under each
  final finding (proof type, description, evidence artifact kind/uri/redaction),
  keyed by finding id.
- `tests/golden/test_idor_report.py` — golden coverage for the proof block (and
  its absence when there's no proof).
- `tests/integration/test_e2e_temporal.py` + `src/quarry_cli/main.py` — close the
  target subprocess `stdout` pipe so the `text=True` `TextIOWrapper` doesn't leak
  as a ResourceWarning.
- `tests/unit/test_vulnerable_fastapi_auth.py` — migrated off FastAPI's test
  client to httpx `AsyncClient` + `ASGITransport` (async, pytest-asyncio auto
  mode). Removes the `starlette.testclient` deprecation at the source — no
  dependency change.
